NetWiv Wayland 실제 입력 검사

자동 검사는 실제 콜백과 상태를 확인합니다. 체크박스는 직접 관찰한 결과만 선택하세요. API 호출 성공만으로 화면 동작이 확인되지는 않습니다. 10분 안에 완료하세요.

개인 정보 입력·붙여넣기는 하지 마세요. 아래 고정 문장만 사용합니다. 결과·스크린샷·환경 목록은 저장하지 않습니다.

1. 네이티브 메뉴 / 트레이 / 키보드

창의 Probe → Native menu action을 선택하세요. GNOME 상단 패널의 NW 아이콘 메뉴에서 Native tray action을 선택하세요. 이 창을 활성화한 뒤 Ctrl+Shift+K를 누르세요.

트레이가 보이지 않으면 성공으로 처리하지 마세요. GNOME의 AppIndicator 지원이 필요할 수 있습니다.

2. IME 입력

한국어 IME로 아래 칸에 한글 입력 확인 123을 직접 입력하고 조합을 확정하세요. 붙여넣기나 자동 입력은 검사에 사용할 수 없습니다.

3. 창 조작 / 포커스 / 화면

창 가장자리를 직접 드래그해 크기를 바꾸세요. 제목 표시줄을 더블클릭하거나 시스템 창 메뉴로 최대화한 뒤 확인 버튼을 누르고, 복원 후 다시 확인하세요.

다른 창으로 전환했다가 돌아오세요. 제목 표시줄로 창을 옮긴 다음 아래 영역도 드래그하세요. 각 동작에서 창이 실제로 움직였는지 직접 관찰하세요.

이 영역을 마우스 왼쪽 버튼으로 드래그 (공식 Window.startDragging)
